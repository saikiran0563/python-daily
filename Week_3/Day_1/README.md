## What I Learned

### CREATE TABLE

Used `CREATE TABLE` to create a table and define columns.

### Constraints

- `PRIMARY KEY` - Unique and cannot be NULL
- `NOT NULL` - Value must be provided
- `UNIQUE` - Duplicate values are not allowed
- `DEFAULT` - Uses a default value if no value is provided
- `CHECK` - Validates data based on a condition

### INSERT

Used `INSERT INTO` to add single and multiple rows to a table.

### UPDATE

Used `UPDATE` to modify existing data.

### DELETE

Used `DELETE` to remove specific rows or all rows from a table.
