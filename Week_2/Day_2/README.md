## Key Concepts

- Instance variables belong to individual objects.
- Class variables belong to the class and are shared by objects.
- Instance methods use self.
- Class methods use cls and @classmethod.
- Static methods use @staticmethod and do not automatically receive self or cls.
- __init__() initializes object data.
- __str__() provides a human-readable representation.
- __repr__() provides a developer-oriented representation.
