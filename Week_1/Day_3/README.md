# Week 1 - Day 3

## Topic
Python Comprehensions

## Concepts Learned

### List Comprehension
- Create lists in a single line
- Syntax: [expression for item in iterable]

### Conditional List Comprehension
- Filter elements using an if condition

### Dictionary Comprehension
- Create dictionaries in a single line
- Syntax: {key: value for item in iterable}

### Set Comprehension
- Create sets in a single line
- Automatically removes duplicate values

## Key Learnings

- Comprehensions make code shorter and more Pythonic.
- List comprehensions create lists.
- Dictionary comprehensions create key-value pairs.
- Set comprehensions create unique values.
- Conditional comprehensions filter data.
