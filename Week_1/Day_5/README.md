# Week 1 - Day 5

## Topic
Python *args and **kwargs

## Concepts Learned

### *args
- Accepts any number of positional arguments
- Stores arguments as a tuple

### **kwargs
- Accepts any number of keyword arguments
- Stores arguments as a dictionary

### Packing
- Collects multiple values into a tuple or dictionary

### Unpacking
- Expands a tuple, list, or dictionary into individual arguments

## Key Learnings

- *args is used for variable-length positional arguments.
- **kwargs is used for variable-length keyword arguments.
- Packing collects values into one variable.
- Unpacking expands values from a collection.
- *args creates a tuple.
- **kwargs creates a dictionary.
